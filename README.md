# My Portfolio

## About

A responsive personal portfolio website built for the Web Development course (Builders Day).
It introduces me, my skills, my project, my education and how to contact me.

I'm Ankit Pandey, a first-year Computer Science & AI student at Scaler School of Technology
and BITS Pilani (Class of 2030), based in Bengaluru, India.

**Live site:** https://ankitpandey-code.github.io/ankit-portfolio/

## Technologies

- HTML
- CSS

No JavaScript, no frameworks.

## Features

- Sticky navigation bar with smooth scrolling to each section
- Hero section with a "terminal" style intro and a blinking cursor
- About, Skills, Projects, Education and Contact sections
- Dark theme with a green accent (colors are stored in CSS variables)
- Flexbox for the navbar, hero and buttons
- CSS Grid for the stats row and the card layouts
- Hover transitions on buttons, cards and the photo
- CSS keyframe animations (`fadeUp` and `blink`)
- Responsive layout with a media query for tablets and phones
